# 粉笔复盘工作台

以「六步复盘法」为核心的本地刷题复盘工具，Go 单二进制交付。

扫码登录粉笔 → 同步刷题数据 → 在工作台完成 **限时 → 订正 → 归类 → 记录 → 总结 → 复习** 完整复盘闭环。

## 功能

| 模块 | 说明 |
|------|------|
| 🎯 复盘工作台 | 待复习/重点/已掌握统计 + 今日复习队列 + 错误类型分布 + 近期练习 |
| 📋 练习历史 | 全部练习记录 + 详情页可视化（单题耗时横向条形图 + 难度/全网正确率分析 + 作答清单） |
| ❌ 错题本 / ⭐ 我的收藏 | 知识点树分组 + 模块/子分类筛选 + 时间筛选（默认近90天）+ 列表内联展开作答/归类/打卡 |
| 📝 单题复盘 | 作答判题 → 解析 → 六类错误归类（可自定义标签）→ 四句话记录（可同步粉笔笔记）→ 重做打卡 |
| 📅 复习队列 | 重点攻坚/待复习/已掌握 分组管理，重做打卡 + 连续做对提示 |
| ⚙️ 账号设置 | 账号信息 + 退出登录 |

## 技术栈

- **后端**: Go 1.22（标准库 + go-qrcode），单二进制
- **前端**: Vue 3 + Vite + Element Plus（Bento 网格风格）+ ECharts，构建产物 embed 进二进制
- **认证**: 粉笔扫码登录（deviceId + 会话 Cookie 双认证），本地持久化
- **数据**: 复盘数据本地 JSON（按账号隔离、原子写、损坏自检备份）

## 构建与运行

```bash
# 前置：Go 1.22+、Node 18+
make build          # 前端构建 + Go 编译（产物: fenbi-workbench）
./fenbi-workbench   # 默认端口 3000，浏览器打开 http://localhost:3000
```

开发模式（前端热更新）：

```bash
cd frontend && npm run dev   # Vite :5173（代理 /api → :3000）
./fenbi-workbench            # 后端 :3000
```

## 六步复盘法

1. **限时做题**：粉笔 App 限时练习
2. **自主订正**：列表展开直接作答判题（解析默认隐藏）
3. **错误归类**：找数瞎/列式乱/计算蠢/掉坑快/死磕傻/读不懂 + 自定义标签
4. **四句话记录**：考点 / 错在哪里 / 正确思路 / 长效提醒（可同步粉笔）
5. **宏观总结**：练习详情填写错误占比/耗时材料/陷阱/做题规范
6. **滚动复习**：复习队列手动标记（待复习/重点/已掌握）+ 重做打卡
